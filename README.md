# ECHO

小さな会社向けに、**繰り返される社内問い合わせ**を記録して集計するアプリです。

同じ質問が何回流れたか、対応に何時間・何円かかっているか、先に書くマニュアルはどれかを出します。画面は **日本語 / English** を切り替えできます。記録した本文そのものは翻訳しません。

## できること

- **記録する** — 1件ずつ残す。本文を打つと、設定のテーマ名・キーワードから候補が出る
- **まとめて取り込む** — Slack のコピー、csv / txt / JSON を追記（既存は消さない）
- **ダッシュボード** — `#社内` / `#社外`（英語では `#internal` / `#external`）で分けて見る。クリックするとそのチャンネルの問い合わせが出る
- **頻度 / 優先** — テーマの件数と、先に書くマニュアル
- **設定** — 時給、集計期間、よく聞かれるテーマとキーワード
- **日本語 / English** — 右上。このブラウザに残る
- **任意の共有 PIN** — 環境変数 `ECHO_ACCESS_PIN`

分類は本文のキーワード一致です。未分類になるときは **設定 → よく聞かれるテーマ** に、実際の本文に出てくる語を足して保存します。すでに入っている記録も再分類されます。チャンネル名では分類しません。

データはアプリを動かしている PC 上の `data/workspace.json` です。同じ社内 LAN の他の PC は、その URL を開けば同じ集計を見ます。クラウドには送りません。画面上の CSV 書き出しはありません。ログイン済みなら `GET /api/workspace` が同じ JSON を返します。

## 使い方

1. [http://localhost:3000](http://localhost:3000) を開く
2. **記録する** で `#社内` か `#社外` を選んで1件入れるか、ログを貼って追記する
3. **ダッシュボード** でチャンネルを選び、中身と頻度を見る
4. **設定** で時給とキーワードを直す
5. 英語で見せるときは右上の **EN**

以前このブラウザだけに残していた集計がある場合は、「記録する」に **社内データに取り込む** が出ます。

## 立ち上げ

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開きます。3000 が埋まっているときは Next が 3001 などを使います。

社内の1台（常時起動できる PC）で本番相当にするなら:

```bash
npm run build
npm start
```

同じ Wi-Fi の他の PC は `http://そのPCのIP:3000` です。

Vercel などのサーバーレスでは再起動でファイルが消えることがあります。小さな会社では社内 PC か、ディスクが残る VPS 向けです。

## 注意

- 実名の問い合わせは Git に上げないでください。`data/workspace.json` は無視設定済みです
- 損失時間 = 対応分数 × 時給。年間は集計期間から換算します。仮定は設定で変えられます
- テーマ分けは本文のキーワード一致です。本番の類似度クラスタに差し替える前提です

## 技術

- Next.js 16（App Router）
- React 19 / TypeScript / Tailwind CSS 4
- 保存: サーバー上の JSON（`data/workspace.json`）
- UI 文言: `lib/messages.ts`（ja / en）
- チャンネル表示: `lib/channels.ts`（保存は `#社内` / `#社外`、画面だけ言語で切り替え）
