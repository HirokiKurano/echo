# テスト

分類・チャンネル・予測・貼り付けは Node のテストランナーで実行します。画面の E2E はまだありません。

## 実行

```bash
npm test
```

`tsx` で `lib/*.test.ts` を読みます。ブラウザは不要です。

## いま見ているもの

| ファイル | 内容 |
| --- | --- |
| `lib/analyze.test.ts` | キーワード分類、件数ランキング、削減時間 |
| `lib/channels.test.ts` | `#internal` → `#社内`、表示名、ボードの既定チャンネル |
| `lib/suggest.test.ts` | 入力の末尾トークン、テーマ候補、挿入 |
| `lib/parsePaste.test.ts` | 行分割、`#チャンネル` プレフィックス |

## 手動確認（画面）

1. 記録する → `#社外` を選んで1件保存 → ダッシュボードで `#社外` だけに出る
2. 本文に「経」→ 経費テーマの候補 → Enter で挿入
3. 設定でキーワードを足して保存 → 未分類だった件がテーマに入る
4. 右上 EN → チャンネルが `#internal` / `#external`。本文は日本語のまま
5. 取り込みは追記が既定。置き換えチェックは既存が消える

## 入れてないもの

- Playwright / Cypress
- PIN ゲートの結合テスト
- `store.ts` のファイル I/O（gitignore の実データを触らない）
