# 対象ユーザー（Target Users）

ECHO は、**社員数が少なく、問い合わせがチャットに流れて消える会社**向けです。ヘルプデスク製品の置き換えではなく、同じ質問の渋滞を数字にして、先に書く文書を決めるための小さな運用ツールです。

## 第一利用者

| 役割 | 使い方 |
| --- | --- |
| 総務・労務・情シス | 聞かれた内容をその場で記録する。チャンネルは `#社内` / `#社外` |
| 管理職・経営 | ダッシュボードで件数・時間・金額と、先に書くマニュアルを見る |
| 社内の「よく聞かれる人」 | 自分が答えている繰り返しを残し、文書化の根拠にする |

想定規模は、社内 LAN の **1台の PC（または小さな VPS）** で足りるオフィスです。全員が同じ `workspace.json` を見ます。

## 使わない想定

- 大規模なチケット管理（Jira / Zendesk の代替ではない）
- 顧客向け公開 FAQ サイト
- Slack の全履歴を自動クロールするボット（貼り付け・手入力が入り口）
- サーバーレスの無料ホスティング（再起動でファイルが消える）

## もう一つの読み手

就職・インターンの面接官です。勤怠や ToDo ではなく、**現場の損失を仮定つきで説明できる題材**として置いています。時給・吸収率・期間は設定で変えられるので、「その数字は妥当か」を議論できます。
